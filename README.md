# 🎨 우리 반 실시간 스케치북 (공개수업용 태블릿 그림 공유 웹앱)

태블릿에서 학생들이 그림을 그리고 [제출]을 누르면, 선생님 컴퓨터/전자칠판 화면에 실시간으로 즉시 나타나는 공개수업 특화 웹 애플리케이션입니다.

---

## 🌟 주요 특징

1. **태블릿 100% 호환 (앱 설치 불필요)**:
   - 교실 칠판의 **QR코드**를 태블릿 기본 카메라로 찍기만 하면 즉시 접속!
   - 손가락 터치, 애플펜슬, S펜, 크롬북 모두 부드러운 드로잉 지원
   - 화면 튕김/스크롤 방지 터치 락 내장

2. **선생님 대시보드 (27명 한눈에 보기)**:
   - 27명 바둑판형 실시간 갤러리 그리드
   - 학생 작품 클릭 시 전자칠판 전체화면 고화질 확대 뷰어 (좌/우 화살표 키로 발표 넘겨보기)
   - 27명 전원 작품을 한 번에 ZIP 파일(`01번_홍길동.png`)로 다운로드
   - 다음 활동을 위한 [새 활동 시작 (전체 리셋)] 기능

3. **서버 비용 0원 (완전 무료)**:
   - Firebase의 무료 티어(Spark Plan) 범위 내에서 학급 인원 트래픽은 100% 평생 무료로 운영 가능합니다.

---

## 🚀 로컬 실행 방법

선생님 컴퓨터에서 바로 테스트해보실 수 있습니다:

```bash
# 1. 패키지 설치 (이미 되어있음)
npm install

# 2. 로컬 개발 서버 시작
npm run dev
```

터미널에 표시되는 로컬 주소(예: `http://localhost:5173`)로 접속하시면 됩니다.
- 학생 화면: `http://localhost:5173/?mode=student`
- 선생님 화면: `http://localhost:5173/?mode=teacher`

*(Firebase 설정 전에도 브라우저 창 2개를 띄워 실시간 로컬 데모 모드로 바로 작동을 테스트해보실 수 있습니다.)*

## ☁️ 무료 배포 및 Firebase 연결 가이드

### 1단계: 무료 Firebase 프로젝트 만들기 (3분)
1. [Firebase 콘솔](https://console.firebase.google.com)에 로그인 후 **[프로젝트 추가]**를 클릭합니다.
2. 좌측 메뉴 **[빌드] → [Firestore Database]** 클릭 후 **[데이터베이스 만들기]**를 누릅니다.
3. 위치는 기본값(또는 `asia-northeast3` 서울)을 선택하고, 보안 규칙은 **[테스트 모드에서 시작]**을 선택합니다.
4. 프로젝트 설정(톱니바퀴) → **내 앱**에서 웹(`</>`) 아이콘을 눌러 앱을 등록합니다.
5. 화면에 나오는 `const firebaseConfig = { ... };` 코드를 복사합니다.

### 2단계: 웹앱에 Firebase 설정 넣기
- 웹 화면 우측 상단의 **⚙️ 톱니바퀴 버튼**을 누르고, 복사한 코드를 붙여넣은 뒤 **[설정 저장 & 연결]**을 누르면 끝입니다!

### 3단계: Vercel 또는 Netlify로 1분 무료 배포 (인터넷 링크 생성)
1. [Vercel.com](https://vercel.com) 또는 [Netlify.com](https://netlify.com)에 로그인합니다.
2. 이 프로젝트 폴더를 GitHub에 올린 후 Import하거나, Vercel CLI(`npx vercel`)로 즉시 배포할 수 있습니다.
3. 배포된 주소(예: `https://my-sketchbook.vercel.app`)를 즐겨찾기해두시면 언제든 공개수업 때 사용하실 수 있습니다!
